## Task

In namespace `signal-ops`, Pod `metrics-relay` is a two-container Pod (containers `relay` and `exporter`), and the on-call teammate needs a quick health read before a shift handoff.

Identify the exact `kubectl` command that retrieves **only** the `exporter` container's logs. Create a file named `metrics-relay.txt` in `/root`. The file should contain only that command — no extra spaces, no extra lines.

When `/root/metrics-relay.txt` contains a correct, runnable command targeting `exporter`, click **Check**.
